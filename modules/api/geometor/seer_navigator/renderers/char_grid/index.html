class geometor.seer_navigator.renderers.char_grid.CharGrid(grid, **kwargs)¶

Bases: geometor.seer_navigator.renderers.base_grid.BaseGrid

Renders each grid cell as a single Unicode square character (default: ‘■’), styled with the cell’s fill color.

You can switch the character to something else (e.g. ‘⬛’, ‘◼’, ‘▣’) if desired.
